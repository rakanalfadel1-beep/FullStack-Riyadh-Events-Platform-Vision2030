# 🎟️ Riyadh Events Platform: Vision 2030

## 📌 Project Overview
Riyadh Events Platform is a comprehensive web application designed to support the Saudi Vision 2030 goals, specifically focusing on Tourism Growth, Quality of Life, and the Entertainment Economy[cite: 7]. The platform serves as a centralized hub for discovering and booking events in Riyadh, including concerts, sports, gaming, cultural shows, and food festivals[cite: 7].

## 🚀 Key Features
* **User Authentication:** Secure registration and login system with bcrypt password hashing and comprehensive input validation[cite: 7].
* **Interactive Booking System:** A 3-step ticket booking wizard featuring an interactive seat selection map, simulated payment processing, and unique booking reference generation[cite: 7].
* **AI Integration:** Features a client-side AI recommendation engine that filters events based on user interests, alongside a 24/7 floating AI Chatbot Assistant for event queries[cite: 7].
* **Community Engagement:** A dynamic feedback system with star ratings and a personal favorites list managed asynchronously via AJAX[cite: 7].

## 🛠️ Technology Stack
* **Backend:** PHP, MySQL (relational database managing users, events, bookings, feedback, and favorites)[cite: 7].
* **Frontend:** HTML5, CSS3, JavaScript (handling slideshows, countdown timers, AI engine, and AJAX)[cite: 7].
* **UI Framework:** Bootstrap 5 for responsive design and components[cite: 7].
